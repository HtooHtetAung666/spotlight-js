Cloud computing is the delivery of computing services over the internet. Most popular services are servers, storages, databases, networking and software. Instead of owning physical hardware and managing on-premises data centers, users can easily set up the entire infrastructure through web-browser and access computing resources from cloud provider like AWS with pay-as-you-go pricing. Compared to on-premises, public cloud models offer more scalability, flexibility, and cost-efficiency, making it a transformative technology across industries.

<Image src={cloud} alt="" />

## Cloud Computing types

1. Infrastructure as a Service (IaaS): Provides virtualized computing resources such as virtual machines and storage. Most control over the infrastructure.

2. Platform as a Service (PaaS): Offers development platforms and tools for building and deploying applications without managing the underlying infrastructure.

3. Software as a Service (SaaS): Delivers software applications over the internet, accessible via web browsers. Least control over IT resources.
